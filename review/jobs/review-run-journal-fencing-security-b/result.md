# Independent review: `run-journal-fencing` (adversarial security lens)

Target: `ultraplan-go`, `internal/runcontrol` byte-identical to frozen `5d54525` (HEAD `c1eb26a` touches only sprint smoke files). All probes ran against a scratch copy at `/tmp/opencode/rcwork`; the target tree and workspace were never modified. Baseline `go test ./internal/runcontrol/` green.

## F1 — Stable operation digests are permanently bound to dead runs; crash recovery wedges TUI retries

**Severity:** Medium (availability/recovery) · **Confidence:** High (mechanism code-read + repo-layer repro)

**Claim.** `operation_aliases` is insert-only with no expiry, rebind, or supersede capability, and every alias conflict is converted into `Existing: true` regardless of the resolved run's state. A TUI-started durable operation therefore can never be re-run after its run reaches *any* terminal state — including `interrupted`, the outcome reconciliation produces in precisely the crash scenario this surface exists for.

**Observable bad outcome.** TUI operation crashes mid-flight → owner lease expires → reconciler terminalizes the run `interrupted` (correct behavior) → user retries the identical action → `AcceptOperation` hits the alias conflict, resolves the dead run, returns `Existing: true` → TUI shows `"matching durable operation already exists"` (tui/app.go:247) bound to the interrupted run. No product path creates a replacement run for that digest until age-based retention deletes the run (~37 days at defaults) or the user perturbs inputs enough to change the fingerprint.

**Trigger/preconditions.** Kill/crash of a TUI-started operation + identical retry after grace. TUI digest = `sha256(CanonicalRequest + "\x00" + InputFingerprint)` (tui/app.go:237-240); canonical form is pure JSON of the request (operations.go:610-617) and the fingerprint hashes deterministic workspace inputs (operations.go:364-372) — stable across restarts by design and pinned by test (`web_operations_test.go:44-45` asserts fingerprint stability).

**Evidence / path.**
- Alias written once at accept, never updated/deleted except CASCADE: sqlite.go:445-455, schema sqlite.go:306-314 (incl. never-used `expires_at`/`recovery_code`/`recovery_guidance` columns).
- Conflict → resolve → return existing with no lifecycle check: durable_operations.go:106-112.
- Only deleter of runs (and thus aliases) is age-based `Compact` (retention.go:142-150).
- Caller scoping verified: CLI passes digest `""` (durable_operations.go:55 — unaffected); web dedup key embeds a single-use, in-memory confirmation token (operation_handlers.go:156-157), so post-restart web retries fail token consumption before reaching the alias and recover with a fresh key — **the wedge is TUI-specific**.
- Empirical repro (scratch copy, package-internal test): duplicate `Accept` with same alias → `ErrConflict`; `ResolveOperationAlias` hands back the terminal run: `RESULT: stable digest resolves to terminal (interrupted) run …; insert-only alias, no rebind/expiry API exists`.

**Existing controls / counter-evidence.** Dedup-on-active is clearly intended and pinned (`durable_operations_test.go:104-112`, active run only); returning an existing *succeeded* run is defensible idempotency. Nothing in code, tests, or TRD justifies treating interrupted runs as live dedup hits; sprint-35 requirements L26 demand resolution to "a durable run, a retained tombstone, or precise recovery guidance" — here it's a durable run with no recovery path. Pack unknowns #2/#3 flagged the shape; this is the concrete failure it implies.

**Fix direction / regression test.** When the resolved run `IsTerminal()`, supersede: mint the fresh run and re-point the alias (or delete-and-reaccept) inside the accept transaction. Regression: accept → force-terminalize → repeat `AcceptOperation(sameDigest)` must create a new run (not `Existing:true`).

## F2 — Keyset pagination compares RFC3339Nano timestamps lexicographically; whole-second instants sort inverted

**Severity:** Low · **Confidence:** High mechanism, near-unreachable trigger today

`List` orders by `updated_at DESC` and pages with `(updated_at < ? OR (= AND run_id < ?))` over raw TEXT (lifecycle.go:230-233). RFC3339Nano trims zero fractions, so `…T10:00:00Z` sorts *greater* than the later instant `…T10:00:00.25Z` (empirically demonstrated). Consequence: a page transition can skip or duplicate a run. Trigger requires a zero-nanosecond timestamp adjacent to a page boundary; production writes come from `time.Now()` (nanos ~never exactly 0), so practical impact is presently negligible — but injected clocks produce such timestamps routinely, so the latent bug is one clock-source change away. Grace/lease predicates are immune (they use `julianday()`; parsing of RFC3339Nano incl. 9-digit fractions empirically verified). Fix: pad fractions or compare via `julianday`. Same string-compare family shifts `Compact` cutoffs <1 s — harmless.

## F3 — Reconciliation decisions are applied without their audit rows when logging fails

**Severity:** Low · **Confidence:** High

Both call sites discard `recordReconciliation` errors (`_ =` at lifecycle.go:352, :411), so terminal/stall decisions commit while `reconciliation_log` silently misses the corresponding rows — the evidence trail degrades exactly when the store is unhealthy, and postmortems cannot distinguish "no decision" from "decision without evidence". Bounded fix: log-at-minimum (local logger) or surface count in `ReconcileReport`. No integrity consequence (decisions themselves are CAS-guarded).

## Defended non-issues (hypotheses raised, then disproved)

- **Hard-quota gate bypass via sanitize stub** — oversize drafts are rewritten to reserved `warning` *before* the gate (sqlite.go:617-622); empirically confirmed admitted at ≥hard quota. Dismissed as exploit: the persisted object is the ~275-byte content-free stub (payload dropped, omission counted) — coherent with deliberate reservation of omission/warning writes under quota pressure; growth is bounded and OS ENOSPC remains the backstop.
- **MAX+1 sequence allocation without verified `_txlock=immediate`** (pack unknown #4) — empirically verified the driver honors it (second `Begin` goes BUSY during a lock-holding read-only txn); gapless sequences across processes/connections are test-pinned (sqlite_test.go:287, process_integration_test.go:15).
- **Lease/grace predicates misparsing stored timestamps** — `julianday()` parses RFC3339Nano correctly incl. 9-digit fractions (verified); clock-jump safety additionally test-pinned.
- **`loadSnapshot` hard-fails (`CodeCorrupt`) when `terminal_outcome` is set but `terminal_at` NULL** (observed during probing; schema CHECK doesn't pin `terminal_at`) — unreachable by product writers (all three set both atomically in one immediate tx); tamper-only. Worth a schema tightening someday, not a defect.
- **Attacker-controlled cancellation reasons / ANSI escape injection into operator terminals** — no user-controlled reason source exists: CLI whitelists 4 literals, web/TUI use fixed strings; repository-level bounds hold.
- **Agent-content exfiltration through allowlisted payload fields** (`tool_result` etc.) — sanitizer + producer filters fail closed (over-broad markers like `sk-` matching `risk-` only inflate omissions); diagnostics surfaces (support export, Health) exclude payload values entirely, satisfying TRD §19.
- **Heartbeat refusal at hard quota killing healthy owners**, **cancellation_state frozen `requested` beside a winner**, **claim-once permanence**, **stall-never-terminalizes**, **unreachable `uncertain` state** — intentional, documented/test-pinned semantics.
- **Reconcile pass-1 budget starving expired-owner scan** (pack unknown #5) — self-draining (≤64 terminalized per 10 s tick), conservative direction, visible via `Health.ReconciliationBacklog`/`OldestBacklogAge`; delay, not denial.
- **`ProposeTerminal` skipping compaction** — winner inserts exactly one bounded event; losers insert nothing; no growth loop.

Fencing core verdict: `verifyFence` + per-statement CAS guards under immediate transactions hold under every race I could construct (claim-vs-reconcile, cancel-vs-append, cancel-vs-terminal, heartbeat-vs-terminalizer); single-winner arbitration and immutable-journal guarantees are real, not just tested.
